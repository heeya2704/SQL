Predictive Demand Schema — ER Diagram (3NF)

Entities are in third normal form: repeating groups (cuisines, restaurant types) are exploded into dictionaries plus junction tables. Ratings use a composite primary key so the same restaurant can appear in multiple Zomato listing contexts without duplicating restaurant attributes. 

erDiagram
    LOCATIONS ||--o{ RESTAURANTS : contains
    RESTAURANTS ||--o{ RATINGS : has
    RESTAURANTS ||--o{ RESTAURANT_CUISINES : tagged
    CUISINES ||--o{ RESTAURANT_CUISINES : used_by
    RESTAURANTS ||--o{ RESTAURANT_TYPE_MAP : classified
    RESTAURANT_TYPES ||--o{ RESTAURANT_TYPE_MAP : assigned

    LOCATIONS {
        int location_id PK
        varchar location_name UK
    }
    RESTAURANTS {
        int restaurant_id PK
        varchar restaurant_name
        varchar url UK
        text address
        varchar phone
        boolean online_order
        boolean book_table
        int approx_cost_for_two
        int location_id FK
    }
    RATINGS {
        int restaurant_id PK_FK
        varchar listed_in_type PK
        varchar listed_in_city PK
        decimal rate
        int votes
    }
    CUISINES {
        int cuisine_id PK
        varchar cuisine_name UK
    }
    RESTAURANT_CUISINES {
        int restaurant_id PK_FK
        int cuisine_id PK_FK
    }
    RESTAURANT_TYPES {
        int rest_type_id PK
        varchar rest_type_name UK
    }
    RESTAURANT_TYPE_MAP {
        int restaurant_id PK_FK
        int rest_type_id PK_FK
    }

Normalization notes

  • 1NF: Comma-separated cuisines and rest_type values are atomic rows, not lists.
  • 2NF: Non-key attributes (address, cost, flags) depend on restaurant_id only, not on part of the ratings composite key.
  • 3NF: Location name lives on locations, not repeated on restaurants. Cuisine names live on cuisines. Listing-specific rate/votes live on ratings.
  • Cardinality: Location 1:N Restaurant; Restaurant 1:N Rating; Restaurant M:N Cuisine; Restaurant M:N Type.
  • ON DELETE CASCADE: Deleting a location deletes its restaurants; deleting a restaurant deletes ratings and junction rows.
